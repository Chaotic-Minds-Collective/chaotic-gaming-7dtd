# 7 Days to Die Integration Roadmap

Start with external Web API/SSE integrations for status, sessions, chat, scheduled messages and administration. Add XML modlets only where native configuration changes are needed. Reserve C# ModAPI/Harmony for requirements that cannot be delivered externally, with explicit EAC/client/crossplay compatibility notes. See the central [plugin catalogue](https://github.com/Chaotic-Minds-Collective/chaotic-gaming-docs/blob/main/plugins/PLUGIN_CATALOG.md).
